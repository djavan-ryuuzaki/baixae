# Avisos de terceiros

O Baixaê é distribuído sob a [GPL-3.0](LICENSE) e inclui os componentes abaixo nos APKs.

| Componente | Uso no app | Licença | Fonte |
| --- | --- | --- | --- |
| youtubedl-android | Executa o yt-dlp, o Python e o ffmpeg no Android | GPL-3.0 | https://github.com/yausername/youtubedl-android |
| yt-dlp | Extração e download dos vídeos | Unlicense (domínio público) | https://github.com/yt-dlp/yt-dlp |
| Python | Interpretador que roda o yt-dlp | PSF License 2.0 | https://www.python.org |
| FFmpeg | Junta vídeo e áudio baixados separadamente | LGPL-2.1+ / GPL-2.0+ (conforme a compilação incluída no youtubedl-android) | https://ffmpeg.org |
| QuickJS | Runtime JavaScript usado pelo yt-dlp no YouTube | MIT | https://bellard.org/quickjs |
| AndroidX (Compose, Room, WorkManager, Media3 e outras) | Interface, banco de dados, tarefas em segundo plano, Marca d'água | Apache-2.0 | https://developer.android.com/jetpack |
| Kotlin e kotlinx.coroutines | Linguagem e concorrência | Apache-2.0 | https://kotlinlang.org |
| Jackson (via youtubedl-android) | Leitura do JSON do yt-dlp | Apache-2.0 | https://github.com/FasterXML/jackson |
| Apache Commons Compress (via youtubedl-android) | Extração dos pacotes do Python e do ffmpeg | Apache-2.0 | https://commons.apache.org/proper/commons-compress |

Os textos completos das licenças Apache-2.0, MIT, PSF e LGPL/GPL estão nos sites indicados. O código-fonte correspondente a cada APK publicado está na tag da mesma versão neste repositório.
