# Threads fora da v1

A ideia original incluía Threads, mas ele não entra na v1: o yt-dlp não tem extrator para Threads (pedido aberto desde 2023, PR não mergeado desde 2024), e manter um extrator próprio de uma Plataforma que muda com frequência seria um custo contínuo só nosso. Também não há Biblioteca padrão "Threads". Threads volta quando o yt-dlp ganhar suporte oficial.
